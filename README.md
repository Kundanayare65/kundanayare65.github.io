# Kundan Portfolio

A production-ready React + TypeScript + Vite portfolio reconstruction based on the supplied PNG reference.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```

## Replace placeholders

- Put the real resume at `public/resume.pdf`.
- Replace placeholder social URLs in `src/sections/Hero.tsx`, `src/sections/About.tsx`, and `src/sections/Footer.tsx`.
- The four project images in `public/` are cropped from the supplied original project screenshot strip.
- Update personal/project content in `src/data/portfolio.ts`.

The PNG reference is visual-only and is not used as the page background.
